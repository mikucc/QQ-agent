# 每日日程（daily-schedule）

给角色一份**全局、虚构的生活时间线**。不是让她念时间表，而是让她知道自己“此刻在哪、在做什么”，聊天时自然带出来。

## 规则

- 每天 **23:30** 生成明天；
- 启动/跨天发现今天没有日程 → 补今天；
- 明天生成失败 → 先用模板兜底，20 分钟后重试；
- 6~10 段，覆盖 00:00~24:00；
- 生成参考：人设、生活圣经、最近三天、心情、重要记忆；
- 注入所有群聊 + 私聊；正文要求“正事优先”，不能因为“在睡觉/出门了”敷衍。

## 数据

```text
data/daily-schedule/days/YYYY-MM-DD.json
```

每段：

```json
{
  "start": "09:00",
  "end": "12:00",
  "activity": "写稿",
  "location": "家",
  "with": "",
  "note": ""
}
```

## 注入

只注入：

- 日期/星期/当前时间；
- 今天是什么日子；
- 此刻在做什么；
- 接下来 1~2 段；
- 今天早些时候 1~2 件；
- “像自己的日子自然说，不要说日程/计划表/时间段”。

## 工具

- `daily-schedule__schedule_view`：看今天/明天/昨天；
- `daily-schedule__schedule_adjust`：临时改今天的计划（被约出去、突然想散步、加班）；
- `daily-schedule__schedule_current`：现在在做什么。

`schedule_adjust` 只改今天/未来，不改过去；一天最多 3 次。

## 生活圣经

在设置里填固定事实：

```text
住：南方小城老小区顶楼
工作：接零散稿子，不用坐班
常去：楼下便利店、河边步道
固定：嗜甜，晚上容易犯困
```

它是虚构设定，不要写真实地址/隐私。

## 与现有模块

- `mood`：低电量更宅，高能量更愿意出门；
- `plastic-memory`：重要/珍贵记忆可以写进日程；
- `proactive`：主动消息也会带同一份日程；
- 不要和 `life-memory` 同时装，功能重叠。

## 注意

- 第一次缺少今天日程时，会等一次模型生成；之后不会每轮生成；
- 生成失败有模板兜底，不会没有日程；
- 电脑睡眠可能错过 23:30，下一次 tick/启动会补；
- 不接生图/穿搭，只做时间线。
