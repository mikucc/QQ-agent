# 注意力门（attention-gate）

群聊唤醒前的本地判断。**不调模型**；沉默时不建运行会话、不烧 token。

## 规则

1. **必醒**：@ 她 / 回复她 / 拍一拍 / 叫她的名字。
2. **不判断“在叫哪个群友”**：不做成员名表、不做呼语/话题分类，避免误判和维护地狱。
3. **其余按兴趣**：基础 15% + 兴趣词 35% + 问句 20% + 情绪 15% + @全体 10% + 主人 15%。
4. **限流**：最短 15 秒、每小时最多 60 次主动唤醒（可调）。
5. **对话延续**：她刚回过这个人，或对方紧接着说“你”，120 秒内视为继续聊，不套用最短间隔。即使 `after-response` 跑在工具执行前、`session.sent` 还是空的，也会用“刚唤醒”的时间兜底。

被叫到不受概率和限流限制。私聊不经过这里，永远唤醒。

## 她自己的称呼

只维护她自己的 2~3 个称呼，不维护群友名单。来源：

- 固定身份：`botName`、`selfNickname`、手动 `aliases`；
- 当前群群名片：自动读取（最可靠，不用手动维护）；
- 明确命名：主人说“以后叫你 X / 叫你 X”；
- 被叫到时的候选：@ 她/回复她时，句首或句尾的称呼累计 3 次才转正。

数据在 `data/attention-gate/self-names.json`。长期不用的别名会降为候选，不会删除固定身份。

## dryRun

`dryRun: true` 时只记录“本来会沉默/唤醒”，返回仍然唤醒，不改变行为。建议先跑一天看日志，再关掉。

日志：

```
[skill:attention-gate] [group:123] 沉默｜基础 15%，命中兴趣词「画画」+35% → 掷到 62，这次沉默
[skill:attention-gate] [称呼] 主人明确命名：肥鱼
```

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总开关 |
| `dryRun` | false | 只记录、不拦截 |
| `interjectChance` | 15 | 基础概率 |
| `interestKeywords` | 小鲸鱼/画画/游戏… | 兴趣词 |
| `questionBonus` | 20 | 问句加成 |
| `emotionBonus` | 15 | 情绪加成 |
| `interestBonus` | 35 | 兴趣词加成 |
| `atAllBonus` | 10 | @全体加成 |
| `ownerBonus` | 15 | 主人加成 |
| `minGapSeconds` | 15 | 最短主动唤醒间隔 |
| `continuationWindowSeconds` | 120 | 对话延续窗口（刚回过对方/对方说“你”） |
| `maxWakePerHour` | 60 | 每小时主动唤醒上限 |
| `aliases` | 空 | 额外名字/别名 |
| `logDecisions` | true | 记录每次判断 |

## 依赖内核

需要 `src/orchestrator.js` 里的 `message.attention` 前置能力：

- 没有插件 / 插件报错 → 默认唤醒，行为不变；
- 只有群聊调用，私聊永远唤醒。

## 边界

- 只做“要不要醒”，不决定“醒了说什么”；
- 不读模型、不调模型；
- 不认识情绪/生活/人格，第一版只做本地规则；后续可以把情绪、关系、记忆接进兴趣分。
