# QQ Agent

![平台](https://img.shields.io/badge/platform-Windows%20%7C%20Electron-lightgrey)
![技术栈](https://img.shields.io/badge/stack-Node.js%20%7C%20原生前端-orange)
![协议](https://img.shields.io/badge/QQ-OneBot%20v11-blue)
![许可](https://img.shields.io/badge/license-MIT-green)

跑在自己电脑上的 QQ 群聊机器人：装完双击启动，扫码登录，填一个模型 Key 就能用。

事件驱动 + **无状态会话**架构——每次处理都是一次独立请求，token 成本恒定可控；所有配置都在图形控制台里完成，不用碰命令行。

> 本项目基于 [K0nd1us/QQ-agent](https://github.com/K0nd1us/QQ-agent) 改造而来，在其基础上重做了人设表达、记忆注入、每日日程、生图工作室和主动消息逻辑。原始项目的"仿真群友"思路是这一切的起点。

## 能做什么

### 像真人一样混群

- 被 @ 或被叫到时回话，平时看心情插嘴；会发文字、表情包、戳一戳，会引用、会 @ 人，知道什么时候该闭嘴
- 短句优先、不总结、不客服腔；有自己的一套口头禅，但会收敛（说多了会被提醒换开头）
- 允许拒绝、允许沉默、允许怼回去——不是有求必应
- 看图：视觉模型直接读消息里的图片；被问"这是什么"时会先给结论，不确定就说不确定

### 记得住人

- **双向长期记忆**：记得谁是什么风格、爱什么梗、雷点是什么，下次自然带上
- **塑料记忆**：自动从对话里挑"值得长期留"的事（答应过什么、在意什么），过时的会被合并/淘汰
- 私聊里记得更细（每轮都抽、条数更多）；群聊控制 token，只带相关的
- 记忆页可查看、手动编辑、单独"更新记忆"

### 有日子可过

- **每日日程**：每天 23:30 生成明天的一天（6~15 段），有作息、有出门、有摸鱼，凌晨会接着昨晚的结尾写
- **转场文案**：每段切换时实时写一句"刚……"的现场细节（去重 + 多角度），15 分钟后失效
- **衣柜**：出门 / 在家 / 睡前各一套衣服 + 一个发型，每天固定，换天再换

### 会发图

- 本地参考库（人物 / 服装 / 场景 / 道具）+ 生图接口，`image_generate` 直接发到当前聊天
- 用户明确要图走宽松额度，主动发图克制；镜头和动作会轮换，不会每张都是同一个姿势

### 有主动性

- 冷场时可以自己开话题，但不凌晨打扰、不打断刚聊起来的天、每个会话每天最多一次
- **约定追踪**：你答应了什么、约好什么时候，到点她会来问一句

### 成本看得见

- 每次调用的 token 和成本精确记录，按天 / 会话 / 模型三个维度统计
- 缓存命中率、峰谷分时计价、图片计费口径都标清楚

## 工作原理

### 无状态会话（成本控制的核心）

1. 群聊消息持续写入本地 JSON 存档（每条带时间和已读状态）
2. 每次有新消息（或主动机会），**新开一个独立会话**：

   ```
   提示词 = 静态系统提示（人设 / 规则 / 工具协议）
          + 角色设定
          + 已读信息（最近 N 条聊天记录）
          + 记忆（相关群友的印象）
          + 未读信息（这次触发的新消息）
   ```

3. 会话结束即弃置，LLM 层面零历史——单次成本恒定，不随聊天量膨胀
4. 处理期间新来的消息只写存档；结束后发现未读就再开一个新会话，直到清空
5. 长期信息走记忆系统持久化，跨运行生效

### 触发档位

响应档位滑条 0~100 无级调节：

| 档位 | 触发条件 |
|---|---|
| 1 | 只回 @ 和拍一拍 |
| 2 | 1 档 + 关键词 |
| 3 | 2 档 + 按概率随机响应 |
| 4 | 全部响应 |

没命中的消息直接标已读，**零 token 消耗**。

## 快速开始

### 三步

```bash
git clone https://github.com/mikucc/QQ-agent.git
cd QQ-agent
npm install
npm run setup     # 下载协议端 + 便携 QQ（幂等，可重复执行）
```

然后双击 `启动QQ机器人.bat`（或 `npm start`），在协议端页签启动 QQ，扫码登录。

### 手动准备

如果 `npm run setup` 下载失败：

1. **协议端**：本项目通过 OneBot v11 接入 QQ，默认适配 SnowLuma（独立第三方项目，不随本仓库分发）。从官方渠道获取后解压到项目根目录，目录名保持 `snowluma`
2. **QQ**：用你机器上已经装好的官方 QQ 即可——setup 会从注册表找到它并复制一份便携副本到 `runtime/qq-portable/`，与日常 QQ 完全隔离
3. **启动**：`npm start`（桌面端）或 `npm run server`（headless，浏览器打开 `http://127.0.0.1:3210`）

### 常用命令

```bash
npm start            # 桌面端启动
npm run server       # headless 模式
npm run setup        # 一键准备运行环境
npm run setup:check  # 只检查是否就绪
npm test             # 全量测试
npm run test:coverage # 覆盖率测试
```

## 配置

设置页顶部的体检卡会告诉你缺什么，按顺序填就行：

1. **接口地址 + Key** → 点「获取列表」自动拉模型 → 选中即切换
2. **测试连通** → 发个 ping 验证地址/Key/模型，显示延迟
3. **白名单** → 从 QQ 账号直接勾选允许工作的群/好友

其它常用设置：

- **人设**：内置角色卡开箱即用，可多套模板一键填充、按会话单独覆盖
- **参与度**：安静 / 普通 / 活跃
- **表情包积极程度**：0~3 档
- **每群独立开关**、私聊开关、屏蔽名单

## 扩展：插件与技能

扩展分两型，按「什么时候该运行」来选：

| 类型 | 放哪 | 靠什么生效 | 谁决定何时执行 |
|---|---|---|---|
| **确定性型（插件）** | `plugins/<id>/` | 能力 `providers` / 钩子 `hooks` | 核心代码：满足条件必然执行，不经过 LLM |
| **LLM 型（技能）** | `skills/<id>/` | 工具 `registerTool` + 提示词片段 | 模型：看工具说明自己判断 |

```
plugins/my-plugin/            skills/my-skill/
  plugin.json  清单              skill.json   清单
  index.js     providers/hooks   index.js     registerTool
```

判据一句话：**规则能写死 → 插件；要理解人话 → 技能。**

其它约定：

- 开关只有一处：`config.skills[id].enabled`，关掉即同时失效工具、能力、提示词片段
- 按能力依赖，不按名字：核心问「谁提供 `llm.request-params`」，不 import 具体扩展
- 扩展的提示词片段优先级被强制压在核心安全规则之下
- 热重载默认开启，放进去即生效（共享机器建议关掉）

## 每日日程与衣柜

日程让她的回答有「今天」的锚点，而不是每次凭空接话。

- **生成**：每天 23:30 生成明天（也可 `schedule_view` 查看/`schedule_adjust` 调整）
- **结构**：6~15 段，覆盖 00:00-24:00，每段有活动、地点、备注
- **跨夜衔接**：凌晨 0-6 点会注入「昨晚（跨夜）」，避免「昨晚洗过澡、凌晨又说去洗漱」
- **转场文案**：段切换时实时生成一句「（刚）……」，去重 + 多角度，15 分钟过期
- **衣柜**：`每日三套 + 发型`，在 `daily-schedule` 的 `wardrobe*` 配置里改候选，名字对应生图库里的条目

人设改安排时，会先过「三问」：他是谁、他认真吗、我想动吗——不会嘴上答应却不改。

## 生图工作室

- **参考库**：`data/image-studio/library/{characters,outfits,scenes,props}`，每个条目一个目录 + `entry.json`，图片放在同目录
- **生成**：`image_generate` 组合参考图 + 提示词，直接发到当前聊天
- **额度**：用户明确要图一档（宽松）、主动发图一档（克制），冷却/每小时/每天都可配
- **选衣服**：没指定时按情境取（在家/出门/睡前），并轮换镜头和动作
- **接口**：OpenAI 兼容 `/images/generations`、`/images/edits`，或 65535 的异步任务接口

参考图选择：人物图保证长相和发色，服装图保证版型，场景/道具按名字匹配；库里没有的条目只按文字描述。

## 主动消息与约定追踪

主动消息不是「定时发自言自语」，而是按动机来：

1. **到点的约定**：你说过「明天考试」「晚点发你」，到点她会来问一句
2. **冷场闲聊**：才有机会轮到随机开话题

闸门：

- 只在 09:00-23:00 主动
- 群里 5 分钟内有活动 → 不插嘴
- 每个会话每天最多 1 次
- 连续 2 次没人接 → 冷却 3 天

约定从对话里抽取（只在出现「明天/答应/说好」这类词时触发，且同一会话 10 分钟内最多抽一次），到点问过后 3 天自动清理。

## 目录结构

```

plugins/       确定性扩展（日程、生图、记忆、心情、注意力门、主人识别…）
skills/        LLM 型扩展（去 AI 味、表情包、语音…）

test/          测试套件

doc/           文档
data/          运行数据（对话、记忆、配置、生图库）——不进版本库
```

## 隐私与安全

- **数据全在本地**：`data/` 里是聊天记录、记忆、配置和生图库，`.gitignore` 已排除，不会被提交
- **Key 只存在 `data/config.json`**，不写进任何源码或文档
- **提交前自动检查**：仓库自带 pre-commit 钩子（`scripts/check-secrets.mjs`），会拦下私钥、`sk-` Key、非空 `apiKey`、Bearer、本机用户路径和误入的 `data/` 文件

  ```bash
  git config core.hooksPath .githooks   # 启用（只需一次）
  node scripts/check-secrets.mjs        # 也可以手动跑
  ```

- **分享部署副本前脱敏**：

  ```bash
  node scripts/sanitize-release.mjs --dry-run
  node scripts/sanitize-release.mjs
  ```

- **联网抓取**：内置 SSRF 防护（DNS 校验 / IP 固定 / 手动跟重定向），图片地址禁内网
- **发送边界**：工具绑定当前会话，模型无法把消息发到别的群；白名单 + 限频

## 常见问题

**Q：需要装 QQ 吗？**
不需要装第二份。setup 会从你机器上已装的 QQ 复制一份便携副本，带独立 `--user-data-dir`，和日常 QQ 互不干扰。

**Q：一定要 SnowLuma 吗？**
不一定。任何 OneBot v11 实现都能接，改协议端地址即可。

**Q：模型只能用 DeepSeek 吗？**
任何 OpenAI 兼容 API 都行（官方 / 中转 / 本地网关），设置里自选模型。

**Q：token 会不会越聊越多？**
不会。无状态会话让每次处理只发固定的一小份上下文，长期信息靠记忆系统。

**Q：她能记住多久以前的事？**
窗口内靠「已读信息」（默认 80 条），更早的靠记忆里的印象；问很久以前的事她会主动查记忆。
